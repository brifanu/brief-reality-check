# Brief Reality Check

Пилотный независимый инструмент для проверки согласованности рекламных целей, бюджета и исходных предположений.

## Функции v0.1
- Четыре типа задач: продажи, лиды, охват, трафик.
- Прямой расчет потребности в бюджете и сравнение с ограничениями.
- Доброжелательное объяснение расхождений и альтернативные сценарии.
- Источник прогнозных параметров и раскрытие формул.
- Печать заключения в PDF.

## Запуск
Для публикации на GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).

Все введенные значения обрабатываются локально в браузере. Математическое соответствие параметров не гарантирует достижимость рекламного результата.
